HTTP command-line client

Run from the vm-manager-docker project folder.

./vmctl list
./vmctl start Kali
./vmctl ssh-info Kali
./vmctl --no-wait deploy-kali Kali-Lab
./vmctl jobs

The client waits for completion by default. With --no-wait it returns a job ID immediately.

REST calls with curl

curl http://127.0.0.1:8080/api/vms

curl -X POST \
  http://127.0.0.1:8080/api/vms/Kali/actions/start \
  -H 'Content-Type: application/json' \
  -d '{}'

curl -X POST \
  http://127.0.0.1:8080/api/commands \
  -H 'Content-Type: application/json' \
  -d '{"argv":["list"]}'

Endpoint reference

POST requests return HTTP 202 with a job ID. Poll GET /api/jobs/{id} for status, results and generated credentials.
